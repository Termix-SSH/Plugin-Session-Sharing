## Overview

Session Sharing lets you share a live terminal or remote desktop session with someone else, and present sessions to a group in meeting rooms.

Read the [docs](https://docs.termix.site/plugins/session-sharing) to set it up and use it.

<br />

## Features

- Share terminal, RDP, VNC and Telnet sessions
- Share by link with anyone, or with a Termix user
- Read-only or read and write
- Links that expire or can be revoked
- Meeting rooms where a presenter shows a session and can hand over control
- Guest links for people without an account

## Support

Found a bug or have an idea for Session Sharing? Open an issue in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-Session-Sharing/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-Session-Sharing/issues/new?template=feature_request.yml). The quickest way to report a bug is **Report an issue** on this plugin's page in the Termix Plugins tab, which fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Please be as detailed as possible, preferably in English. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
